# 🏧 DecodeLabs ATM System

A simple **ATM System** that allows users to perform basic banking operations through a menu.

## 📌 Features

* Check account balance
* Deposit cash
* Withdraw cash
* Prevent withdrawal when there is insufficient balance
* Reject invalid amounts
* Display updated balance after transactions
* Exit the ATM safely

## 🏦 Available Options

```text
=== WELCOME TO DECODELABS ATM SYSTEM ===

--- ATM Main Menu ---
1. Check Balance
2. Deposit Cash
3. Withdraw Cash
4. Exit
```

### 1. Check Balance

Displays the current balance in the account.

### 2. Deposit Cash

Allows the user to enter an amount and add it to the account balance.

### 3. Withdraw Cash

Allows the user to withdraw money if the account has sufficient balance.

### 4. Exit

Closes the ATM system and displays a goodbye message.
